# 第 1 课作业数据获取指南（上位机版）

> 你 = 上位机（你自己的电脑）
> 小车 = ESP32 智能小车
> 当前固件走 **WiFi UDP**，USB 线不能代替 WiFi/IP。

## 第一步：先确认三件事

1. 你的电脑能跑 ROS2：

   ```bash
   ros2 --version
   ```

   不报“找不到命令”才算可以。

2. 你的电脑和小车连同一个 WiFi。

3. 小车固件里的 Agent IP 等于你电脑的 IP。

## 第二步：查你电脑的 IP

Windows：

```powershell
ipconfig
```

Linux / WSL：

```bash
ifconfig
```

找到 IPv4 地址，一般是 `192.168.x.x`，记下来。

## 第三步：启动 Agent

```bash
ros2 run micro_ros_agent micro_ros_agent udp4 --port 8888
```

这个窗口不要关。给小车通电，等 Agent 显示类似“client connected”的消息，说明小车已经连上你。

## 第四步：确认话题

另开一个 ROS2 终端：

```bash
ros2 topic list
```

可以看到 `/cmd_vel`、`/odom` 或 `/odom_raw`、`/car_status`，可能还有 `/imu`、`/scan`。

如果只有 `/odom_raw` 没有 `/odom`，说明固件还没改成 PPT 标准话题，先记下实际看到的名字。

## 第五步：量频率

一次量一个，看到 `average rate` 就抄数字，然后按 `Ctrl+C` 停。

```bash
ros2 topic hz /odom
```

```bash
ros2 topic hz /imu
```

```bash
ros2 topic hz /scan
```

量 `/cmd_vel` 需要边遥控边测：

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

再开一个终端：

```bash
ros2 topic hz /cmd_vel
```

回到 teleop 窗口按 `i`、`j`、`k`、`l`，抄下频率。

## 第六步：查坐标系和时间戳

```bash
ros2 topic echo /odom --once
```

看 `frame_id`。再连续观察几秒：

```bash
ros2 topic echo /odom
```

`header.stamp` 必须一直变大，不能回退。`/imu` 同样做一遍。

## 第七步：teleop 与急停

轮子架空先测：按 `i` 前进、`k` 停、`j` 左转、`l` 右转。

落地后小范围再试一次，按 `k` 或 `s` 要马上停。

注意：当前固件没有断线自动刹车，不要直接关 teleop 窗口，先按停止键再关。

## 第八步：填 Excel

填 `第1课_接口契约表_模板.xlsx`：

- 姓名、组号、学号、提交日期
- 四个话题的实测频率
- 时间戳单调填“是/否”
- 坐标系按实际 echo 结果填
- 两人签字
- Sim-to-Real 预测：终点误差(cm)、用时差(s)
- S1 轮径(mm)、轮距(mm)

所有数字必须来自实测命令输出。

## 遇到问题怎么办

- Agent 没有“client connected”：先查电脑和小车是否同一个 WiFi，再查固件里的 Agent IP。
- `topic list` 缺少 `/imu`：固件还没补，先补固件再测，不能编数字。
- `ros2 run ...` 提示找不到包：电脑上还没装 micro-ROS Agent / teleop 工具。
- 小车一开机自己跑：当前固件会执行预置路线，测试时先把轮子架空，不要马上下地。
